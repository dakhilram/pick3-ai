HOW TO READ THIS DASHBOARD

Play type changes the matching rule, not the draw.

Box sums the three-position scores of all distinct permutations of each unordered group (one, three, or six). The Box backtest compares unique groups, with a fair baseline adjusted for the sizes of the selected groups. “Auto-selected” chooses each digit-position model using earlier chronological validation. The last test segment is reserved for an independent report. Hot/cold strategies describe history; they do not imply that a digit is due. Uniform baseline treats all 1,000 exact outcomes equally.
